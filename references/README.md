# references/

Analysis of other illustration systems: other Microsoft systems, and
inspiration from around the web.

**This directory is committed, so everything in it must be public-safe.**
Original analysis only. No pasted internal documentation, no internal artwork,
no internal-only links. Anything that cannot meet that bar goes in
`private/references/` or `private/notes/` instead. See `private/README.md`.

## How to add one

Copy `_template.md`, fill it in, add a line to `index.md`.

Every entry answers the same questions in the same order. That is deliberate.
The value of this directory is that entries can be read **across**, so that
"how do four different systems handle small sizes" is one scan rather than four
readings. An entry that skips sections or invents its own structure breaks
that.

A link with a sentence of praise attached is not an entry. If a system is worth
filing, it is worth twenty minutes.

## What to look for

The questions this corpus is meant to answer, roughly in priority order:

1. How do other systems decompose an illustration into named parts, and does
   that decomposition survive contact with a real library?
2. Which ones support retheming, and what did they give up to get it?
3. Has anyone built a working composition tool, and what is the unit of reuse?
4. Where do systems break down as the library grows past a few hundred pieces?
